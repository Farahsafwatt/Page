# Flutter Navigation App

A simple Flutter app with three pages: **Home**, **About**, and **Contact**.

## Features
- Home → About → Contact navigation using named routes
- Page name text on every page
- Image on the Home page (`assets/images/home.png`)
- Icons on every page
- `Scaffold`, `AppBar`, `Column`, `Center`, `Padding` layout widgets
- Custom app theme (bonus)

## Run
```bash
flutter pub get
flutter run
```

## Structure
```
lib/
  main.dart          # app + routes
  theme/app_theme.dart
  pages/
    home_page.dart
    about_page.dart
    contact_page.dart
```
